**Goal:** Complete local Library organization with composable segment, sort, direction, source filtering, density, persistence, and reset behavior.

**Architecture:** A pure `LibraryCollectionQuery` transforms the existing lightweight snapshot; SwiftData remains untouched. `LibraryViewPreferences` persists only presentation values, sanitizing them against the current snapshot. `LibraryView` renders adaptive controls and distinguishes genuine from filtered empty states.

**Tech Stack:** Swift 6, SwiftUI, UserDefaults, Swift Testing, iOS 17/macOS 14.

## Global Constraints

- Sort/filter never mutates Library records.
- Sources are derived only from normalized domains already saved locally.
- Empty source selection means All Sources.
- Default: Recent, activity descending, all sources.
- Unread Updates has fixed unread-first order; do not expose a meaningless reverse direction.
- Preserve comfortable/compact/list behavior and preference.

- [ ] **Step 3: Implement stable query behavior**

```swift
public enum LibrarySortKey: String, CaseIterable, Sendable { case activity, title, unreadUpdates }
public enum LibrarySortDirection: String, CaseIterable, Sendable { case ascending, descending }

public struct LibraryCollectionQuery: Equatable, Sendable {
    public var segment: LibrarySegment
    public var sortKey: LibrarySortKey
    public var sortDirection: LibrarySortDirection
    public var sourceDomains: Set<String>

    public func apply(to snapshot: LibrarySnapshot) -> [LibrarySeriesSummary] {
        let normalizedSources = Set(sourceDomains.map(LibraryIdentityNormalizer.normalizedSourceDomain))
        let filtered = snapshot.series(for: segment).filter {
            normalizedSources.isEmpty || normalizedSources.contains(LibraryIdentityNormalizer.normalizedSourceDomain($0.sourceDomain))
        }
        return filtered.sorted(by: comparator)
    }
}
```

Implement comparator rules: activity uses `lastReadAt` with nil last, title uses folded localized-standard text, unread groups `true` before `false`, and every tie resolves by normalized title then UUID string. Ignore direction for `.unreadUpdates`.
