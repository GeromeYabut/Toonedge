# Story 13.5 Library Sorting Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add deterministic, persisted, sorting-only Library organization with Recent activity newest-first as the default.

**Architecture:** A pure `LibraryCollectionQuery` orders the existing segment projection from one lightweight local snapshot. `LibraryViewPreferences` persists presentation state in UserDefaults, while a focused native sort menu maps user-facing choices to the query without loading detail data or mutating Library metadata.

**Tech Stack:** Swift 6, SwiftUI, UserDefaults, Swift Testing, XCTest/XCUITest, iOS 17, macOS 14.

## Global Constraints

- Keep existing Recent, Reading, Planned, Dropped, and Completed segments.
- Default and Reset are Recent plus recent activity newest-first; Reset preserves density.
- Recent activity uses `LibrarySeriesSummary.lastReadAt`; missing dates sort after dated titles in both directions.
- Title supports A–Z and Z–A with deterministic ties.
- Unread updates uses fixed unread-first ordering, retains all other titles, and exposes no direction control.
- Persist segment, sort key, sort direction, and the existing density locally.
- Sorting composes with the selected lifecycle segment and uses only one lightweight local snapshot.
- Never mutate series, chapters, progress, or update metadata and never add network calls or per-item detail hydration.
- Preserve Comfortable, Compact, and List layouts, genuine empty states, update refresh, and Series Detail navigation.
- Do not add a Sources button, source selection, source preference keys, source-filter summaries, or source-filtered empty-state recovery.
- Do not modify, merge, or clean up the paused Reader zoom worktree.

- [ ] **Step 3: Implement the minimal pure query**

Define:

```swift
public enum LibrarySortKey: String, CaseIterable, Equatable, Sendable {
    case activity
    case title
    case unreadUpdates
}

public enum LibrarySortDirection: String, CaseIterable, Equatable, Sendable {
    case ascending
    case descending
}

public struct LibraryCollectionQuery: Equatable, Sendable {
    public var segment: LibrarySegment
    public var sortKey: LibrarySortKey
    public var sortDirection: LibrarySortDirection

    public static let `default` = LibraryCollectionQuery(
        segment: .recent,
        sortKey: .activity,
        sortDirection: .descending
    )

    public func apply(to snapshot: LibrarySnapshot) -> [LibrarySeriesSummary]
}
```

Activity compares known dates before unknown dates regardless of direction. Activity ties use a folded normalized title and then lowercase UUID text. Title reverses only the folded title comparison and uses UUID as the final stable tie. Unread groups `true` before `false`, then applies activity newest-first and the same stable ties. Ignore direction for unread behavior.
