## Goal and boundaries

Preserve Library, chapters, progress, recent reading, cache metadata/files, settings, cookies, website data, and persisted Library source/sort/density preferences. Preserve Story 13.3 destination routing, deduplication, clipboard precedence, and the final explicit-web action. Story 13.4 zoom remains paused and independent; Stories 13.5 sorting and 13.9 source filtering remain outside this change.

## Implementation order

1. Management contract, isolated history persistence, memory parity, rollback/no-op/durable-store tests, and Xcode membership.
2. Shared manager injection, explicit stored UUID provenance, managed-only recent rows, and independent history-load failure recovery.
3. Exact UUID deletion, synchronous recomposition before backfill, race/duplicate guards, retryable feedback, sibling visible controls, and equivalent accessibility action.
4. Settings pending-confirmation contract, cancellation/no-op, guarded clear, disabled in-flight state, success/failure, and reconfirmed Retry.
5. Persistent synthetic UI fixture seeded only by explicit reset; relaunch durability, row eligibility, cancellation/failure, accessibility, and protected-state isolation. Establish all Library preferences explicitly and omit resets on relaunch.
6. Independent reviews, focused/full package verification, simulator compilation plus UI verification on both dedicated devices, attachment inspection, QA evidence, and tracker reconciliation.

Each task uses tests-first behavior changes, a fresh implementer, an independent spec/code-quality review, and reviewable local commits.
