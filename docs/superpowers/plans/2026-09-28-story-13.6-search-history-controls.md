# Story 13.6 Search-History Controls Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let users delete one local search-history item or clear all history without affecting any other local or browser data.

**Architecture:** Extend the recording contract with narrowly scoped management operations implemented by the existing repository. Story 13.3's `SearchOverlayViewModel` owns row deletion and recomposition; `SettingsViewModel` owns confirmed clear-all feedback. Both receive the same dependency through `AppDependencies`.

**Tech Stack:** Swift 6, SwiftUI, SwiftData, Swift Testing, iOS 17/macOS 14.

## Global Constraints

- Delete only `StoredSearchHistory` records.
- Do not delete Library, chapters, progress, recent reading, cache metadata/files, settings, cookies, or website data.
- Individual deletion is offered only for persisted recent links/searches.
- Canceling clear confirmation performs no operation.
- Failure retains or reloads existing visible state and offers retryable feedback.
