## Test resource boundaries and manifest schema

Use existing `app/Tests/ToonEdgeAppCoreTests/Fixtures/` with globally unique names:

- `compatibility_matrix_v1.json`: manifest; not an analysis fixture.
- `matrix_payload_*.json`: every new payload fixture, using the production schema.
- `matrix_dom_*.html`: every new raw HTML fixture.

The **explicit matrix fixture set** is all regular source files matching those two fixture prefixes/extensions. Legacy JSON names are excluded. The source set and packaged set must both equal the manifest's referenced fixture set. Shared HTML resources may be referenced by multiple rows/states; every file must have at least one classification. Manifest row IDs must be unique; file names need not be unique across rows.

Schema version 1 is an object with `schemaVersion: 1` and `cases: [...]`. Each row declares:

| Field | Type / semantics |
| --- | --- |
| `id` | Unique stable String |
| `capability` | Test-only enum: embeddedHTML, hydratedDOM, browserSession, imageDelivery, requestContext, negativeDecorative, challenge, authentication, paywall, errorPage, protectedViewer, canvasOrBlob, unsupportedPagination, browserOnly |
| `coverage` | Test-only enum with raw values `covered`, `partial`, `unsupported-by-policy` |
| `analysisFixture` | Optional basename ending `.json`; required for payload evidence |
| `htmlFixture` | Optional basename ending `.html`; required for WebKit evidence |
| `registry` | default, empty, syntheticBrowserSession, syntheticPaginated, syntheticBrowserOnly |
| `phase` | static, beforeHydration, afterHydration, profileInitial, profileFollowUp |
| `variants` | Explicit source-attribute variants where relevant; empty for non-parameterized rows |
| `expected.parserPath` | Actual DetectionParserPath raw value |
| `expected.disposition` | Actual ReaderEntryDisposition raw value |
| `expected.candidateCount` | Nonnegative Int equal to orderedCandidates.count |
| `expected.orderedCandidates` | Array of objects `{id: String, url: String}`; exact normalized order |
| `expected.readerURLs` | Ordered String array; empty when Reader is ineligible |
| `expected.extractedPrevious`, `expected.extractedNext` | Explicit nullable URL strings on decoded analysis |
| `expected.sessionPrevious`, `expected.sessionNext` | Explicit nullable URL strings on result Reader session |
| `expected.readerAllowed` | Bool; must agree with disposition/session and nonempty Reader URLs |
| `expected.requiredHardBlocks` | Array of real DetectionHardBlock values; assert subset because nonviableSession can also be present |
| `expected.retry` | Actual DetectionRetryRecommendation raw value |
| `evidence` | Required evidence kinds: payloadDecoding, webKitDOM, browserModel, requestHeaders, retryPolicy |
| `limits` | Required nonempty text; explicitly states what the evidence does not establish |

Reject unknown enum values, unsupported versions, empty IDs, empty evidence, rows with neither resource, path traversal, duplicate IDs, missing explicit expected-link keys, impossible counts, and inconsistent eligibility. Do not derive expected URLs from detector output. Runtime HTML variants substitute only declared attribute tokens, never expected outcomes. Resource helpers strip the declared extension when calling Bundle.module.url(forResource:withExtension:); inventory keeps full filenames.
