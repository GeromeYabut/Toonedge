# Story 13.7 Generic Compatibility Matrix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove best-effort generic compatibility across rendering patterns with a machine-readable matrix, sanitized fixtures, and parameterized production-path tests.

**Architecture:** Test resources contain neutral-domain page-analysis fixtures and one manifest declaring their expected capability outcomes. A test-only decoder loads the manifest, verifies fixture completeness, sends each payload through `ProfileAwareChapterDetector` and `BrowserViewModel`, and reports covered, partial, or unsupported-by-policy behavior. Production code never reads the manifest.

**Tech Stack:** Swift 6, Swift Testing parameterized tests, JSON fixtures processed by SwiftPM, existing detection/browser contracts.

## Global Constraints

- Validate rendering capabilities, not named-site counts.
- At least one positive fixture must use an unregistered domain and `.genericHeuristic`.
- Fixtures contain no credentials, cookies, personal history, or unnecessary copyrighted image data.
- Negative policy cases must remain unavailable.
- A fixture pass is not a live-domain guarantee.

- [ ] **Step 1: Add parameterized detector assertions**

```swift
@Test(arguments: try CompatibilityFixtureExpectation.loadManifest())
func fixtureMatchesCompatibilityExpectation(expectation: CompatibilityFixtureExpectation) throws {
    let page = try DetectionPageAnalysis.loadFixture(named: expectation.fixture)
    let result = ProfileAwareChapterDetector(registry: SiteProfileRegistry(profiles: [])).detect(page: page)
    #expect(result.diagnostics.parserPath == expectation.parserPath)
    #expect(result.readerEntryDisposition == expectation.disposition)
    #expect(result.candidates.count == expectation.candidateCount)
    #expect((result.readerSession != nil) == expectation.readerAllowed)
    #expect((result.readerSession?.previousChapter != nil) == expectation.hasPrevious)
    #expect((result.readerSession?.nextChapter != nil) == expectation.hasNext)
}
```

- [ ] **Step 2: Add Browser presentation assertions**

For each fixture, feed the result to `BrowserViewModel` and assert automatic creates a pending session, recommended shows the primary banner, manual shows the secondary tool, and unavailable shows neither.
