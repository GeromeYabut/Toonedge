# Story 12.1 Adaptive Editorial Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish system-adaptive quiet-editorial tokens and reusable borderless interaction primitives without changing feature behavior.

**Architecture:** SharedUI owns semantic palette, typography, surface, press-state, and motion policy. Existing feature screens adopt new primitives in later stories; `TECard` is not changed globally. AppShell consumes adaptive chrome while Reader canvas remains controlled by `ReaderSettings`.

**Tech Stack:** Swift 6, SwiftUI, Swift Testing, XCTest/XCUITest, iOS 18.6 simulator.

## Global Constraints

- Preserve Home, Library, Downloads, and Settings as the four primary tabs.
- Preserve Browser/Reader routing, conservative detection, local-first persistence, and explicit View Original Page behavior.
- WEBTOON and protected GlobalComix remain browser-only.
- Do not change SwiftData schema, detection thresholds, parser behavior, or Reader canvas semantics.
- Custom interactive targets are at least 44×44 points.
- Utility screens follow system appearance; Reader canvas stays independent.
- Do not stage or modify the three protected QA screenshots.

```swift
enum ReaderCanvasPalette {
    static func values(for canvas: ReaderCanvas) -> ReaderCanvasPaletteValues {
        switch canvas {
        case .charcoal: .init(background: .init(red: 0.05, green: 0.055, blue: 0.075), foreground: .white)
        case .black: .init(background: .black, foreground: .white)
        case .paper: .init(background: .init(red: 0.89, green: 0.86, blue: 0.78), foreground: .init(white: 0.10))
        }
    }
}
```

Migrate Reader canvas/background/foreground uses away from adaptive `ToonEdgeColor.background` and `textPrimary` in this task, before any screen story branches.
