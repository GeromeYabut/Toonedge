# Story 13.3 Saved-Library Search Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add deterministic, offline saved-series matches to universal search and route them to native Series Detail.

**Architecture:** The repository exposes a lightweight `LibrarySearchItem` projection. `SearchOverlayViewModel` loads that projection and search history once, then a pure ranker composes typed destinations with existing suggestions. `AppRouter` remains the only navigation owner.

**Tech Stack:** Swift 6, SwiftUI, SwiftData, Swift Testing, iOS 17/macOS 14.

## Global Constraints

- Search remains web-first and must not become a catalog.
- No network request or detail hydration per keystroke.
- Clipboard exact match remains first and explicit web search remains visible.
- Saved results work offline and do not create search-history rows.
- Approved non-promoted sources remain absent from built-in site suggestions.

- [ ] **Step 3: Implement typed destinations and scoring**

```swift
public enum SearchSuggestionDestination: Equatable, Sendable {
    case browserInput(String)
    case librarySeries(LibrarySearchItem)
}

public struct LibrarySuggestionRanker: Sendable {
    public func rank(query: String, items: [LibrarySearchItem], limit: Int) -> [LibrarySearchItem] {
        let needle = normalize(query)
        return items.compactMap { item -> (Int, LibrarySearchItem)? in
            let title = normalize(item.title)
            let score: Int
            if title == needle { score = 0 }
            else if title.hasPrefix(needle) { score = 1 }
            else if orderedTokenPrefix(needle, title) { score = 2 }
            else if allTokensContained(needle, title) { score = 3 }
            else { return nil }
            return (score, item)
        }
        .sorted { ($0.0, normalize($0.1.title), $0.1.id.uuidString) < ($1.0, normalize($1.1.title), $1.1.id.uuidString) }
        .prefix(max(0, limit)).map(\.1)
    }
}
```

Implement `normalize` with folding for case/diacritics, punctuation-to-space replacement, whitespace collapse, and POSIX locale. Implement token helpers as pure private functions.

```swift
@MainActor
public final class SearchOverlayViewModel: ObservableObject {
    @Published public var query = ""
    @Published public private(set) var history: [SearchHistoryEntry] = []
    @Published public private(set) var libraryItems: [LibrarySearchItem] = []

    public func load() async {
        async let history = historyRecorder?.recentSearchHistory(limit: 12) ?? []
        async let library = libraryProvider.librarySearchItems()
        (self.history, self.libraryItems) = await (history, library)
    }
}
```

Compose existing suggestions with bounded ranked Library results in the approved order. Move query and validation state out of `SearchOverlayView`. Keep empty-query Library results suppressed.
