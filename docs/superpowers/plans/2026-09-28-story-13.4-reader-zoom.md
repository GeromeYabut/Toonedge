# Story 13.4 Reader Zoom Implementation Plan

**Historical plan, superseded for execution on 2026-10-06:** The user selected persistent zoom with a sticky fitted-size baseline and deliberate breakthrough in the same inward pinch. The hard `1x` minimum and assumed production strip-transform integration below are no longer the approved implementation direction. See [the revised design](../specs/2026-10-06-story-13.4-sticky-baseline-zoom-design.md). Preserve these historical tasks; do not execute or mark them complete from policy-only results. A replacement executable plan follows user review of the revised design. Closed research budgets remain closed.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add transient focal-point pinch, bounded pan, double-tap zoom, and accessible reset to the existing lazy long-strip Reader.

**Architecture:** A pure `ReaderZoomState` owns scale, anchor, translation, and clamping. A focused SwiftUI modifier applies gestures around the existing strip while leaving its `ScrollView` as the only vertical-scroll owner at `1x`. Reader chrome stays outside the transform.

**Tech Stack:** Swift 6, SwiftUI `MagnifyGesture`/`SpatialTapGesture`, Swift Testing, iOS 17/macOS 14.

## Global Constraints

- Scale range is exactly `1x...3x`; double tap toggles `1x` and `2x`.
- At `1x`, existing vertical scrolling and progress behavior are unchanged.
- Zoom is never persisted and resets on session change/dismissal.
- Zoom cannot alter page order, aspect ratio, canvas, or progress.
- Reduce Motion suppresses nonessential reset animation.

- [ ] **Step 3: Implement the pure state**

```swift
public struct ReaderZoomState: Equatable, Sendable {
    public private(set) var scale: CGFloat = 1
    public var translation: CGSize = .zero
    public private(set) var anchor: UnitPoint = .center
    public var isZoomed: Bool { scale > 1.001 }

    public mutating func setScale(_ value: CGFloat, anchor: UnitPoint, viewport: CGSize, content: CGSize) {
        self.scale = min(3, max(1, value))
        self.anchor = anchor
        translation = clamped(translation, viewport: viewport, content: content)
        if scale == 1 { translation = .zero }
    }

    public mutating func reset() { scale = 1; translation = .zero; anchor = .center }
}
```

Implement clamping from scaled overflow on each axis. Convert gesture/tap coordinates to a `UnitPoint` clamped to `0...1`.

- [ ] **Step 3: Implement the modifier**

```swift
public struct ReaderZoomInteractionPolicy: Equatable, Sendable {
    public let scale: CGFloat
    public var allowsChapterScroll: Bool { scale <= 1.001 }
    public var showsResetAction: Bool { !allowsChapterScroll }
}

public struct ZoomableReaderContent: ViewModifier {
    @Binding var zoom: ReaderZoomState
    let viewport: CGSize
    let content: CGSize

    public func body(content view: Content) -> some View {
        view
            .scaleEffect(zoom.scale, anchor: zoom.anchor)
            .offset(zoom.translation)
            .simultaneousGesture(magnificationGesture)
            .gesture(panGesture, isEnabled: zoom.isZoomed)
            .highPriorityGesture(doubleTapGesture)
    }
}
```

Track magnification/pan deltas with `@GestureState`, commit only at gesture end, and use `SpatialTapGesture(count: 2)` so the tap location sets the focal anchor. Do not attach the existing single-tap chrome gesture inside this modifier.
