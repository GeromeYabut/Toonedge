# Story 13.9 — Library saved-source filtering design

Date: 2026-10-05. Approved through the Library mockup discussion and the instruction to implement the divider as part of 13.9.

## Outcome

Readers can combine lifecycle segments, the five existing sort choices, and inclusive multi-select saved sources. A 44-point sliders icon opens one native Sort & filter sheet. A short muted vertical divider separates the density controls from refresh and organization tools.

## Approved interaction

- Preserve Comfortable, Compact, and List density choices. The mockup showed two icons; production has three and the canonical story requires preserving density.
- Keep the collection count small. Show a compact source summary: All Sources, the selected domain, or N sources selected. Include the selected sort as quiet text when space allows; wrap at large text sizes.
- The sliders entry has accessibility label Sort and filter library and a value describing both current sort and sources. Tint or dot indicates a nondefault sort or active source restriction; this does not replace the textual summary.
- Present one sheet with a Sort by picker, Sources multi-selection rows, All Sources, Reset Library organization, and Done. Source rows come only from the complete saved snapshot, with normalized domains and per-source saved-title counts. No recommendations or external source links.
- Changes apply and persist immediately; Done or dismissal closes the sheet without rollback. Selecting All Sources clears selection. Tapping the last selected source also returns to All Sources. Selecting every currently available source remains explicit selection, so newly saved sources do not unexpectedly appear.
- Reset restores Recent, activity descending, and All Sources, preserving the saved density. Keep the popup open until Done. A filtered empty result also offers Reset Library organization.
- Divider: 1 point wide, 18–20 points tall, muted border color, 8–12 points of spacing. Decorative and hidden from accessibility. It must not reduce the 44-point button targets. At narrow widths or accessibility sizes group controls on separate rows rather than causing overflow.

## Data and policy

Use existing LibraryIdentityNormalizer.normalizedSourceDomain (trim whitespace/newlines, lowercase); do not collapse www or merge different subdomains. Exclude blank domains from selectable options. Blank-domain titles still appear under All Sources. Options derive from snapshot.series, not the visible segment and not recentReadSeries alone. The source filter composes after segment selection and before existing deterministic sorting. Never alter saved metadata or refresh scope.

Persist a normalized, deduplicated, deterministically sorted string array under ToonEdge.Library.selectedSourceDomains. Invalid/missing preference types yield All Sources while preserving other valid fields. Repair against the complete snapshot only after it has loaded: intersect with available saved sources, persist any repair, and fall back to All Sources if empty. Do not repair against initial empty loading state or a selected segment.

Empty reason priority: genuinely empty saved collection retains Nothing saved; a segment empty before source filtering retains No titles in this section; a nonempty segment hidden by active source selection says No titles match your sources and explains the active restriction, with Reset. Filter changes, Reset, refresh, and returning from Series Detail reuse the same complete-snapshot repair.

## Architecture and files

Extend LibraryCollectionQuery and LibraryViewPreferences; add a focused source-option model only if useful. Keep domain normalization, selection repair, and composition in testable models. LibraryView coordinates loaded snapshots, preference writes, and sheet presentation. A focused LibraryOrganizationSheet view owns the shared popup, reusing LibrarySortChoice rather than creating another sorting policy. Existing views and refresh services remain otherwise unchanged. New production Swift files require explicit Xcode Sources membership as well as SwiftPM discovery.
