## Interfaces and behavior

`ReaderFittedLayout` is immutable and carries foundation geometry, usable viewport size, chapter canvas size and unresolved page indexes. Its failable initializer preserves full-width Fit Width and centered 92%-width Fit Screen, aspect ratio, finite nonnegative spacing before/between/after pages, and a viewport-sized minimum canvas. Missing metadata uses the current 430-point default or explicit positive finite placeholder; known invalid metadata rejects rather than becoming a placeholder. Caller-owned revisions let later decoded metadata produce new geometry without mutating prior snapshots.

`ReaderPresentationTransform` is immutable and carries layout, scale, bounded translation and inverse logical viewport. Its initializer projects a session-scoped semantic anchor toward a required viewport-local point. Nonoverflow horizontal canvas centers; nonoverflow vertical canvas chooses a fixed reachable anchor-derived placement, then ignores vertical pan. Overflowing axes clamp to chapter bounds. Pan starts from current bounded translation, preventing hidden overshoot on reversal. Forward projection returns the actual point, not the requested point if centering/clamping makes it unreachable. Invalid/nonrepresentable arithmetic rejects; empty layouts cannot provide anchor-based presentation.

The inverse viewport feeds the existing materialization selector. Neither provisional geometry nor visible selection is native/decoded acknowledgement or progress permission. Scale policy bounds/detent remain caller-owned, not duplicated here. Geometry ordering, interaction epochs, frozen reading anchor versus inspected focal ownership, reconciliation/cancellation/Reset and repository fences remain later responsibilities.
