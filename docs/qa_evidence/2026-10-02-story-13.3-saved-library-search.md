## Delivered behavior

- A lightweight local `LibrarySearchItem` projection and `LibrarySearchProviding` capability expose saved title, ID, source domain, lifecycle, optional current chapter, and optional cover URL. No persistence schema migration is needed. Matching does not load Series Detail or chapter collections.
- A pure ranker normalizes case, diacritics, punctuation, and whitespace, then orders exact title, title prefix, ordered token prefix, and all-token containment matches. Stable title/UUID ordering and duplicate-ID handling make results deterministic; Search shows at most five saved matches.
- Search loads Library projection and history concurrently once per presentation. Query edits compose in memory, without per-keystroke network or repository work. Empty query does not list Library content; absence of the Library capability preserves existing suggestions.
- Typed saved destinations synchronously dismiss Search and open native Series Detail by ID, without web-history writes. Browser destinations retain existing URL/query validation and asynchronous history recording without delayed router mutation.
- Saved rows show `Saved in Library`, local lifecycle, and available chapter context. Saved subtitles wrap at normal and accessibility text sizes; minimum actionable height remains 44 points. Removed saved records use native unavailable recovery and return to Library.

## Approved requirements exception

On 2026-10-02 the user approved keeping the explicit final web action outside ordinary typed-destination deduplication. An exact copied-URL query therefore keeps the copied-link action first and the explicit web action last, even when both have the same browser destination. Duplicate ordinary rows for that destination are suppressed. Saved results still deduplicate by series ID. URL/query classification and web-history semantics do not change.

The exception is recorded in PRD section 8.11, UX Search requirements, design section 6.3, the implementation plan's Global Constraints, and Story 13.3 acceptance criteria. An exact-copied-URL model regression covers it.
